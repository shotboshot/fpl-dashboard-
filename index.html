Captaincy —
Score = attack + fixtures. Attack = (form ×2 + xGI/90 ×8 + set-piece bonus) × start reliability. xGI (expected goal involvements per 90) measures chance quality, separating a real threat from a lucky streak. The set-piece bonus rewards the first-choice penalty taker — the most reliable edge in the game that raw stats miss. Start reliability uses starts per gameweek, so an impact sub can't pass as a nailed starter. Fixtures = (6 − official difficulty) ×3 per fixture — doubles count twice, blanks score zero. The vice is the best option from a different club. xP is FPL's own expected-points forecast, shown as an independent second opinion — when it disagrees loudly with this model, that disagreement is the interesting bit.
